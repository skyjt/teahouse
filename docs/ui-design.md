## 1. 设计基调

**以稳定桌面 IM 为骨架，吸收 Apple Design 的材质、空间一致性和即时反馈原则**：三栏结构保持熟悉，层级依靠留白、材质重量与克制色彩建立。"安静、可靠、精致"落到具体手段上：

- **一个主题色**点缀全局（按钮、选中态、自己的气泡底色），其余全部中性灰阶；主题色定为**茶青 `#3D8B6B`**（决议 #1）。
- **系统字体栈**：`PingFang SC / Microsoft YaHei / Noto Sans CJK`，正文 14px，绝不用衬线、不用艺术字。
- **图标统一为项目内自绘线性 SVG**（1.6px 描边、圆角端点、继承当前文字色），不混用拟物/彩色图标，不用 emoji 充当系统图标；设置图标必须画成清晰齿轮，不使用放射状“太阳”隐喻。Win7 / UOS 缺字平台不可靠，头像和内置 emoji 子集的可见形态使用 Twemoji 本地 SVG 子集兼容渲染，输入框编辑态也必须覆盖，协议与复制仍保留原始 emoji 字符。
- **品牌 logo 使用统一的“茶杯气泡”标识**：杯身兼具对话气泡轮廓，右侧保留杯把，左下伸出对话尾。**v0.15.9 起以用户提供的 SVG 套件作为唯一品牌源（决议 #107）**：任务栏/Dock、标准 logo、小尺寸 logo、菜单 logo、macOS 菜单栏 outline、深浅背景和横向 logo 都保留为本地 SVG；应用内 `PantryBrandLogo` 直接加载 SVG，托盘和打包图标也从 SVG 光栅化生成，不再手写茶杯轮廓。历史背景：v0.5.28 曾改为饱满实心填充风（决议 #64），v0.15.6/#104 与 v0.15.8/#106 为参考图手绘过渡版。
- **动效克制**：150-220ms 缓动，按压在 pointer-down 阶段立即缩放到 0.97-0.98；只用于反馈、层级和状态变化，不做自动循环过场。动效路径与触发源保持空间一致，允许用户立即反向操作。
- **材质与形状（决议 #216，#219/#231 修订）**：结构层使用轻半透明背景、柔和内描边和有色阴影表达层级；导航 / 列表材质较厚，聊天头部 / 输入区材质较轻。磨砂（`backdrop-filter`）只用于真正压住内容的浮层（菜单 / popover / 模态遮罩 / toast）；Win7 / Linux 运行时画像为软渲染时，这些浮层统一使用实色表面、关闭磨砂并收紧阴影。容器 12-16px、控件 8-10px、胶囊 999px，按用途固定，不混用随机圆角。
- **窗口铺满契约（决议 #217）**：主窗口 Naive UI Provider 使用 `abstract` 模式，只提供主题上下文、不生成布局 DOM；动态根与 `.shell` 继续保持完整的 100% 高度链。默认 960×640、最小尺寸和最大化 / 还原后，导航、列表、内容区都必须铺满窗口可用高度，不得以内容高度收缩或在底部留下空白。
- 深色主题 v0.4（roadmap），实现时颜色全部走 token 变量，先把底子留好。
- **组件底座（决议 #215/#216/#232/#233）**：Naive UI 承载标准表单、搜索输入与常规操作反馈。设置窗口使用 Input / Select / Switch / Button / Provider；主窗口使用 Provider、搜索 Input 与主要 Button，`GroupCreator` 的普通文本输入和页脚操作、`ProfileCard` 的备注输入和资料页操作同步接入现有主题。`SetupWizard`、`ForwardDialog` 继续列为后续普通表单复用候选；高密度成员复选框、已选成员标签、消息工具栏、右键菜单、聊天输入器保留项目实现。主题覆盖集中映射茶青、明暗 token、8-16px 形状标尺、系统字体和克制动效。三栏结构、会话 / 联系人列表、聊天气泡、文件 / 图片 / PK 卡片、品牌与系统图标、窗口控制、截图及图片查看器保留项目实现；不引入 vfonts、xicons、远程字体或在线素材。

## 2. 主窗口：三栏结构

```
┌──────┬──────────────────────┬────────────────────────────────────────┐
│  我  │ [搜索]        [+]   │ (头像) 张三 · 在线 · 某某科技/研发部/后端组 ⋯ │
│      ├──────────────────────┼────────────────────────────────────────┤
│ 聊天 │ ● 张三        10:24 │              ┌──────────────────────┐   │
│ 聊天 │   好的，收到    (2)  │              │ 需求文档发我一下？     │   │
│      │ 讨论组          9:15 │              └──────────────────────┘   │
│ 通讯 │   李四: [图片]       │   ┌────────────────────┐               │
│ 通讯 │ ○ 王五        昨天  │   │ [文件] 需求文档v3.docx │            │
│ 录   │   [文件] 设计稿.zip  │   │ 2.4 MB   已送达      │               │
│      │                      │   └────────────────────┘               │
│      │                      ├────────────────────────────────────────┤
│ 设置 │                      │  表情 截图 图片 文件                     │
│      │                      │  输入消息…                              │
└──────┴──────────────────────┴────────────────────────────────────────┘
  68px      272px（可拖拽）              自适应，≥560px
```

| 栏 | 内容 | 规格 |
|---|---|---|
| ① 导航栏 | 上：我的头像（点击=编辑资料）→ 聊天 → 通讯录；下：文件柜（决议 #283）→ 刷新全局用户 → 设置 | 68px 固定（决议 #68，为容纳 mac 红绿灯由 56px 加宽）；**中性浅灰底（决议 #70，微信式，`--rail-bg`，右细线分隔列表栏）——图标默认深灰、选中/hover 茶青高亮**，让 mac 红绿灯落在浅色上自然；聊天/通讯录主入口图标 25px，底部工具组（文件柜 / 刷新 / 设置）图标 21px；图标带未读总角标 |
| ② 列表栏 | 随导航切换：会话列表 / 通讯录；顶部搜索框常驻 | 272px 固定；后续恢复拖拽时范围 220-340px |
| ③ 内容区 | 聊天界面 / 联系人资料卡 / 空状态 | ≥560px；未选会话时显示品牌 logo 空状态 |

- 窗口最小 960×640，记忆上次大小与位置；关闭按钮默认最小化到托盘（设置可改）。
- **沉浸式无标题栏**（决议 #49/#51/#52）：主窗与设置窗不显示系统标题栏，三栏内容直通窗口顶部。macOS 保留原生红绿灯，**主窗红绿灯在导航栏左上角 (9,7)**（贴合窗口圆角视觉中心）（决议 #68：导航栏由 56px 加宽至 68px 容纳标准红绿灯，回到微信式三栏左上角位置；此前决议 #51 曾临时移到列表栏顶部 x=68，与 UI 不协调已废弃）；设置窗红绿灯在侧栏左上 (12,10)。Windows / Linux 在右上角自绘窗口控制按钮（最小化 / 最大化·还原 / 关闭，关闭悬停红底白字）。窗口顶部 32px 为隐形拖拽带（可拖动、双击最大化还原）：macOS / Windows 用系统 / CSS 拖拽区，**Linux 因 CSS 拖拽区不可靠改为 JS 拖拽**（决议 #52，对用户行为无差异）。导航栏头像、列表搜索框、聊天头部内容均从拖拽带下方开始；全屏弹层（向导、转发、图片查看器等）层级高于拖拽带，交互不受影响。
- **文件柜按钮（决议 #283/#284）**：导航栏底部工具组最上一格（更新提示之下、刷新之上），`cabinet` 图标 21px，点击**在主界面内切到文件柜页签**（形态见 §8.2），选中态与聊天 / 通讯录同一套；不加角标，未设共享目录也可点。
- **刷新全局用户按钮（决议 #115 / #162 / #197）**：放在导航栏底部工具组、设置按钮正上方，使用 `refresh` 线性图标。仅当设置里至少有一个扫描网段时可点；**可点状态下每次点击先弹出居中二次确认**（决议 #197），用户确认后才启动全量扫描。扫描中按钮进入加载态并禁用，图标外圈显示环形进度（决议 #162，由原下挂直条改为环绕图标的 conic 细环），进度代表“已发出探测地址 / 总地址”。完成后短暂停留再淡出，避免把左侧栏变成常驻状态面板。
- **全量刷新二次确认弹窗（决议 #197/#216）**：布局骨架对齐「移除会话」确认（决议 #125）——`position:fixed` 半透明遮罩 + 居中圆角卡片（约 **300px**、16px 圆角），`role="dialog"` + `aria-modal`。**信息克制**：无长说明 / 来源 / 脚注；顶部用**暖色警示圆标**（`warning` 三角叹号，琥珀系，非危险红）表达「留意代价」，标题居中。**不**用危险红主按钮。

  | 元素 | 规格 |
  |---|---|
  | 警示标 | 居中 48px 圆：暖琥珀底 + 线性 `warning` 图标（提醒而非恐吓） |
  | 标题 | `刷新全局用户`（15px 半粗，居中） |
  | 摘要 | 仅一句：`将探测 N 个网段` |
  | 网段列表 | 只列 CIDR（等宽），浅底圆角行；最多 **4** 条；超出 `另 N 个` |
  | 操作 | 顶部分隔线后右对齐：`取消` + 茶青 `开始扫描` |
  | 关闭 | 遮罩 / 取消 / **Esc** → 不扫；「开始扫描」→ 既有 `scanAllRanges` |
  | 边界 | 无网段或扫描中：按钮禁用不弹窗。设置页单网段 ⟳ 不使用本弹窗 |

  动效克制：短淡入；`prefers-reduced-motion` 关闭。不引入组件库、不用系统 `confirm()`。
- **左侧导航悬停说明（决议 #116/#117/#118/#119/#212/#216/#238）**：聊天、通讯录、刷新全局用户、设置按钮均使用自绘中文 tooltip；tooltip 不得由 CSS `:hover` / `:focus-visible` 直接触发，必须在鼠标于按钮上真实移动后再计时约半秒显示，pointer 离开立即清理，避免应用启动、默认焦点或静止鼠标位置导致误弹。不使用原生 `title`，避免系统黄框和设计语言冲突。tooltip 采用单体圆角深色标签，不做箭头、不做位移，显隐只保留短透明度变化，避免显示/消失时出现“菱形 + 矩形”的拆件感。自己头像悬停时不显示普通 tooltip，而是在头像右侧显示个人信息卡；信息卡在真实鼠标进入头像 120ms 后出现，启动焦点或键盘焦点不得误弹。头像、到卡片之间的透明桥接区和卡片自身属于同一个悬停范围，指针进入卡片后继续保持，离开整个范围才收起。个人信息卡采用单一外层容器：顶部以大头像、昵称和「本机账户」建立主身份层；中部以淡茶青区域重点展示本机 IPv4；组织与设备名采用无底色键值行；节点 ID 收进最弱层级页脚。端口不在个人信息卡展示，仍可在设置「网络」中查看和修改。卡片保留单行截断、16px 圆角、克制阴影以及浅色 / 深色主题等价层级。

## 3. 列表栏 · 会话列表（导航=聊天）

- 条目：头像（带在线小圆点）、名称、最后消息摘要、时间、未读角标；免打扰会话仍显示未读数量，但角标改为灰色，区别于普通红色强提醒。
- **选中态**（决议 #71，视觉由 #216 更新）：当前会话使用弱茶青材质底、左侧 3px 茶青内强调线和主文字高对比；时间与摘要继续使用次级文字，未读角标保持语义红。该方案减少整条实色块的视觉重量，同时保持当前位置清晰。hover 使用更浅的中性材质。
- 摘要规则：`李四: [图片]`、`[文件] 设计稿.zip`、`[PK] 猜拳` / `[PK] 骰子`（不展示结果）、草稿优先显示红字 `[草稿] …`。
- 排序：置顶在前，其余按最后消息时间倒序（微信同款）；**置顶会话整条加淡灰底色**（`--bg-pinned`，决议 #126），与普通会话一眼区分，hover / 选中态仍优先覆盖。
- 右键菜单：置顶 / 免打扰 / 移除会话（**决议 #125**：点击先弹二次确认弹窗，说明「移除后聊天记录将被删除」；确认后会话立即从列表移除并删除聊天内容，但底部居中浮出「已删除与『X』的聊天记录」+「撤回」按钮，**倒计时 10 秒**；10 秒内点「撤回」立刻恢复（期间未落库），超时才真正删除聊天记录（消息 + 全文索引 + 会话条目）。早期"只移出列表、不删历史"的行为已废弃）。
- 顶部 `[+]`：发起讨论组（多选联系人，见 §7.1）。

## 4. 列表栏 · 通讯录（导航=通讯录）

```
[搜索]
▾ 讨论组
   # 产品讨论组 (8人)
▾ 某某科技 (23/41 在线)
   ▾ 研发部 (12/18)
      ▾ 后端组 (5/7)
         ● 张三  Windows  ← 在线
         ● 李四  macOS
         ○ 王五            ← 灰显 + 灰色状态点，沉底
      ▸ 前端组 (4/6)
   ▸ 设计部 (3/8)
▸ 未分组 (2/5)
```

- **三级树：公司 ▸ 部门 ▸ 团队 ▸ 成员**，逐级折叠，每级标题显示（在线/总数）；资料字段空缺的层级自动跳过，全空归入"未分组"。
- 组内排序：在线优先，再按拼音；普通联系人行以行尾绿色 / 灰色圆点表达在线状态，离线者头像与昵称继续灰显，昵称旁不重复显示“离线”（决议 #17/#252）。
- **历史联系人持久保留**：凡是出现过的节点永久留在通讯录（离线灰显），重启不丢。不提供手动删除（对方还在网内时删了也会回来）；"清理 90 天未上线联系人"为后续版本能力（决议 #150 起不再摆置灰占位，做好再加）。
- **资料自动刷新（防"机器换人"）**：对方上线时、改资料时即时更新；在线期间心跳每 30s 携带资料版本号，发现版本变化立刻拉取最新资料——机器没换、用的人换了昵称/部门，最迟半分钟内通讯录就纠正过来。
- 单击成员 → 内容区显示**联系人资料页**：顶部为圆形头像、昵称/备注、在线状态与组织路径；中部按“备注 / 详细信息”分组展示本地备注输入、IP、主机、平台、最近在线时间；底部提供「保存备注」「发消息」动作。资料页使用内容区完整页面布局，靠留白和细分割线组织信息，不使用突兀的居中小浮卡。双击成员 → 直接进入该联系人的单聊界面（复用打开会话探活，决议 #40）。
- 资料页可**设置备注名**（仅本机生效，列表与搜索优先按备注显示，决议 #22/#40）。
- 顶部固定「讨论组」分组，列出已加入的组。
- 开启内网通兼容模式后，通讯录增加固定「内网通兼容」分组（决议 #194/#195），位于讨论组之后、组织树之前。条目显示兼容昵称 / 主机名、`内网通 · IP:端口` 副文字和在线状态点；昵称右侧显示小型描边徽标「内网通」。离线条目灰显并显示「离线」。兼容联系人不展示公司 / 部门 / 团队资料，也不进入普通组织树；单击显示简版资料，双击打开兼容会话。

## 5. 内容区 · 聊天界面

**头部**：单聊在头部显示对方头像（右下角在线/离线状态点）+ 昵称，昵称下方以小字显示在线/离线状态 · 对方 IP（在线茶绿、离线灰，决议 #81）。IP 是内网排障关键信息，副标题必须单行完整展示，不使用省略号截断（决议 #88）。点击头像/昵称这块用户名字区域，在头部下方弹出紧凑资料框，展示头像、备注/昵称、组织、IP、主机、平台、在线状态，并可直接修改对方备注。备注仅本机可见，保存后会同步影响会话列表、通讯录和搜索显示。**该资料入口的鼠标反馈只改变昵称文字颜色为茶青，不铺整块 hover 背景、不做按下缩放；完整热区与键盘焦点轮廓继续保留（决议 #84/#227）。**群聊显示圆形群头像 + 组名 + 人数；没有自定义图片时沿用成员群组图标。聊天头部与左侧列表搜索栏**等高（84px）**、顶部都让出 32px 拖拽带，底部分隔线跨栏连成一条，视觉统一（决议 #127）。**打开会话即触发一次探活**，约 2s 内以真实结果刷新状态，离线则显示灰字"离线"——防止对着"假在线"的人发消息（F-DISC-8）。右侧 `⋯` 打开会话设置（置顶/免打扰/查看成员/清空本会话记录）。群聊点人数 → 右侧弹出群信息面板（含「+ 添加成员」）。**面板覆盖右侧一整列**（绝对定位、从顶到底、盖在消息之上而非挤压消息，决议 #67）；成员每项显示紧凑圆形头像 + 在线/离线状态点（绿/灰，头像始终彩色，与私聊/会话列表一致；决议 #82 由原「离线灰显」改）。**私聊头部在 `⋯` 左侧再放一个「文件柜」图标按钮（决议 #273）**，点击打开对方的共享文件柜面板（形态见下方「文件柜面板」）；按钮在对方离线、未设共享目录、把我关成"不共享"或版本不支持（未声明 `shr1`）时灰显，鼠标悬停以自绘 tooltip 说明具体原因（「对方离线」/「对方未开启文件柜」/「对方未对你开放」/「对方版本不支持」），灰显口径与决议 #17 一致。群聊头部不出现该按钮。

**文件柜面板（决议 #273）**：形态复用群信息面板——绝对定位覆盖聊天区右侧一整列（相对 `.chat`，top/bottom 0、左边框 + 阴影、z 高于消息、顶部留 32px 拖拽带），**宽度 320px**（比群信息面板的 248px 宽，容纳文件名与大小两列），盖在消息之上而非挤压布局，可边聊边浏览；同一时间只显示一个右侧面板，打开文件柜会收起会话设置类浮层。自上而下四段：① **头部**——26px 圆头像 + 标题「XX 的文件柜」+ 权限徽标（「只读」/「可上传」，决议 #283 由底栏上移）+ 「在文件柜里打开」图标按钮（带着当前对端切到 §8.2 的文件柜页签）+ 关闭 `✕`；② **面包屑行**——`文件柜 / 设计稿 / 2026`，可点任意一级跳回，左侧「返回上级」箭头按钮，右侧「刷新」图标按钮（重新从第 0 页拉取）；③ **列表**——每行 36px（决议 #283 由 40px 收紧），左侧 20px 文件类型图标（复用现有 `file-types` 图标集，目录用文件夹图标），中间名称单行省略，右侧小字显示大小（面板宽度放不下修改时间列，目录不显示大小）；行 hover 淡灰底，**单击选中、双击进目录**（决议 #283 起与窗口版一致，原「单击目录即进入」取消），行首在 hover 或已勾选时显示复选框；顶部可全选当前页；键盘与右键菜单同 §8.2。列表按"目录在前、再按名称"排序，滚动到底自动加载下一页（每页 200 条），加载中显示骨架行；`.` 开头的隐藏项不出现。空目录显示居中空态「这个文件夹是空的」；单目录被截断时列表底部显示 `--text-3` 小字「目录内容过多，仅显示前 5000 项」。④ **底栏**——左侧选中摘要（权限徽标已上移到头部，决议 #283），右侧主按钮：勾选了条目时为茶青实心「下载（N）」，未勾选且我有写权限时为「上传到 TA 的文件柜」，无写权限时该按钮不出现。**上传按钮的语义在任何层级都一样**（永远上传到对方文件柜里以我命名的子目录，与当前浏览到哪一层无关），按钮下方常驻一行 `--text-3` 小字说明「文件会放进 TA 文件柜的『我的名字』文件夹里」，避免用户误以为传到当前目录。面板也接受直接把文件 / 文件夹拖进来上传（有写权限时高亮拖拽区，无权限时显示禁止态）。下载与上传的进度、速率、取消复用现有文件卡的状态语义，就地显示在底栏上方的一条进度行里，**不进聊天流**。请求超时或被拒时，列表区就地显示原因与「重试」（如「对方已关闭文件柜」「操作太频繁，请稍后再试」）。**首屏与翻页的失败态必须分开（决议 #278）**：首屏（进目录 / 刷新 / 面包屑跳转）失败才把列表整片替换成居中错误态；**滚动翻页失败只在列表末尾追加一行横排小字 + 「重试」，已经加载出来的条目一律保留**——对方的列目录限流是 10 秒 5 次，连滚几页撞上 `busy` 是常态，清空列表会让人误以为文件没了。翻页失败后暂停自动续拉，直到用户点「重试」，避免继续滚动反复撞限流。**切换会话时面板一并收起**：留着会直接挂到新对端身上，若新对端离线或不支持，会出现「头部按钮已灰、面板却开着报错」的矛盾状态。

**兼容会话头部（决议 #194/#195）**：内网通兼容联系人打开后仍复用聊天内容区，但标题旁显示「内网通」徽标，头部副标题固定为「内网通兼容 · IP:端口 · 功能受限」，右侧菜单只保留置顶、免打扰、清空本会话记录和查看兼容资料。资料框展示昵称、登录用户、主机名、IP、端口、分组、编码来源、最近发现时间和兼容能力，不出现组织资料、版本升级、窗口震动、PK、群聊、自更新或文件直发入口。

**消息区**：

- 从会话列表、联系人、搜索联系人、通知 / 托盘 / 震动等入口打开会话时，消息区默认加载最新 50 条并滚到最新消息；重新打开软件或从托盘恢复后也按最新入口处理。历史搜索结果跳转仍居中定位目标消息，并显示“回到最新”。当前会话新增消息时，仅当用户本来贴近底部或消息是自己发送时自动贴底，避免阅读历史时被打断（决议 #111/#133/#192）。
- 气泡：对方靠左使用轻浮起表面，自己靠右使用主题色浅底；文字气泡与文件卡统一为四角等弧的 14px 圆角。文字气泡不绘制顶部高光或内高光，对方气泡只保留极轻外阴影，自己气泡保持纯色平面（决议 #228）。连续消息间距保持紧凑。群聊中对方消息在左侧显示发送者圆形头像，私聊消息不在气泡旁显示头像。
- 时间分隔：间隔 >5 分钟插一条灰色小字时间；跨天插日期。
- 文本消息：链接自动识别可点；仅气泡本身可右键=复制 / **转发**（选目标会话，P1）/ 撤回（自己的、5 分钟内；撤回项与复制 / 转发等高并保持单行，左侧固定「撤回」，右侧以小号等宽数字显示 `mm:ss`，超时或不可用原因也放右侧并整体灰显；最后 10 秒才增强倒计时危险色，决议 #63/#251），消息行空白区域不触发菜单；右键菜单靠近窗口边缘时自动避让，不被裁切。转发目标弹窗经 Teleport 挂到 renderer 全局顶层，静态暗色遮罩覆盖完整主窗口，弹窗始终高于消息列表、聊天头部、输入区和局部浮层；打开后焦点进入弹窗，遮罩 / 取消 / `Esc` 均可退出（决议 #230）。
- PK 消息：气泡本身右键仅保留「撤回」（自己的、5 分钟内，倒计时规则同文本）；不提供复制、转发或添加到表情。撤回后只隐藏这一条 PK 气泡，不影响别人之后另发的 PK 消息。
- 图片消息：等比缩略图（最大 280×280）内嵌显示，点击打开**独立图片窗口**（决议 #94/#95/#96/#97/#98/#99/#100/#101/#102/#103/#105/#158/#191），不在主聊天窗内强制覆盖，用户可继续聊天、搜索或拖动主窗口。图片窗口为普通可移动/可缩放桌面窗口，系统标题栏默认显示图片文件名并承担关闭能力；内容区为暗色画布，图片按初始规则居中展示：若原图宽高均小于当前屏幕工作区 70%，以 100% 原始尺寸打开；若宽或高超过 70% 阈值，则按先到阈值的边等比缩放到 70% 内并显示缩放比例。小图仍不强制放大，但窗口外框与内容区设最小尺寸，内容区至少保留 560×360 的暗色画布空间，避免底部工具条因图片过小被压缩到拥挤重叠。渲染时 `<img>` 的显示宽高必须显式等于 `naturalSize * zoom`，图片平面用窗口中心 `50% + offset` 定位，`transform` 只负责自身居中与旋转，避免大图/极端比例图片出现布局盒子与视觉尺寸不一致或溢出后贴左上。操作菜单为**底部半透明浮层**，覆盖在图片窗口下方，包含缩放比例、缩小 / 放大 / 适应窗口 / 原始大小 / 左旋 / 右旋 / OCR 识别或查看结果 / 复制全部 / 另存为，不再放内部关闭按钮；按钮 32px 热区、8px 圆角、茶青 active 态，OCR 识别中以同一菜单内的短状态文案展示进度。支持鼠标滚轮缩放、拖拽平移、双击在适应窗口与原始大小间切换（从适应放大到原始大小时以鼠标所在图片坐标为锚点），`Esc` 关闭，`+/-` 缩放，`0` 原始大小，`F` 适应窗口，`R` 旋转；加载失败时在中央显示轻量错误态。小图片加载后自动 OCR 但不自动弹窗，大图片需用户点击识别；用户点击底部 OCR 按钮时，若已有缓存或识别完成，则在图片窗口内打开**无全屏遮罩的文本结果窗**（右侧浮窗，标题“识别结果”，正文为原生 textarea，底部有复制全部与关闭）。用户在 textarea 内使用系统文本选择 / 复制，图片上不再显示 OCR token、命中框、文字光标、拖选高亮或局部复制按钮；OCR 不再接管图片上的 pointer 事件，图片拖拽、缩放、旋转始终按看图器本体处理。同一图片的 OCR 结果由主进程会话级内存缓存，图片重新打开后先恢复识别文本并可一键打开结果窗，不重新读取图片或再次运行本地 PaddleOCR。图片窗口使用 `pantry-img://transferId` 显示图片，另存为复用主进程保存对话框并挂在图片窗口上，不暴露本地路径；OCR 字节通过受限 `transferId` 读取，交给内置 PaddleOCR PP-OCRv6 tiny + onnxruntime-web 本地 wasm 识别，不展示本地路径。右键菜单含**「复制」/「转发」/「添加到表情」/「撤回」**；「撤回」仅自己的图片、发送后 5 分钟内、对端支持媒体撤回时可用，右侧状态按 #251 显示剩余时间或「不可用」；撤回后图片气泡隐藏，并禁止继续通过该消息打开图片。复制经主进程 Electron 原生剪贴板写入系统图片剪贴板，粘贴到输入框后按图片发送（决议 #137）。添加成功/失败以紧贴消息侧边、垂直居中的小胶囊反馈：对方消息显示在气泡右侧，自己消息镜像到气泡左侧。群聊图片显示在群会话内，发送端一条气泡汇总给在线成员的多条点对点传输；群聊图片超过 10MB 时退化为普通文件卡片，接收者手动接收。
- **低性能平台 OCR 覆盖规则（决议 #231）**：上一条的小图自动 OCR 只适用于 macOS 与非 Win7 Windows。Win7 / Linux 的 `softwareRendering` 画像停用自动 OCR，用户仍可从底部工具条手动识别；OCR 图源使用异步文件读取，识别、缓存、复制和纯本地边界保持。
- **滚动媒体加载（决议 #232/#234）**：聊天图片 / 表情消息、记录搜索缩略图和表情包网格只在接近滚动视口时加载，并使用异步图片解码。静态聊天图片与记录搜索图片优先读取 320px WebP 派生缩略图；首次接近视口且缓存未命中时显示原有加载占位，由 renderer 按原图宽高直接请求缩小解码、写入缓存后展示，避免 `<img>` 持有全尺寸解码面。GIF、APNG、动画 WebP 和最长边 ≤320px 的小图直接读取原图，保留动画与清晰度。进入视口后的点击、右键菜单、加载失败占位与打开原图行为保持；独立看图窗口、截图画面和首屏品牌图保持立即加载。
- **图片像素防护（决议 #234）**：内联图片单边上限 8192px、总像素上限 3200 万。发送时发现真实格式不支持、扩展名伪装、文件头损坏或像素超限，自动以普通文件卡发送；原图查看、OCR、复制、收藏和缩略图生成前均复核同一条件。用户点击图片仍打开通过校验的原图；派生缩略图只服务聊天流与搜索结果，不替换原始文件。
- **发送图片选择器（决议 #235）**：输入区“发送图片”按钮打开专用多选对话框，只展示 PNG/JPG/JPEG/GIF/WebP/BMP；普通文件与文件夹分别由相邻的“发送文件”“发送文件夹”按钮选择。图片选择器返回后仍由主进程复核扩展名并执行决议 #234 的真实格式 / 像素门禁，异常或超限内容按既定规则显示为文件卡。
- **文件主动取消状态（决议 #236）**：发送方点击文件卡“取消”后，单聊与群聊文件卡使用灰色状态显示“发送取消”；接收方自行取消下载，以及发送方收到对端取消时继续显示“已取消”。主动取消进入终态后不再变成红色“传输失败”，真实传输错误仍使用红色失败状态。消息行的发送状态图标同步使用灰色取消标记，避免与错误状态混淆。
- **表格粘贴提示条（决议 #270）**：输入框识别出表格后**不再自动发送**，原文照常插入草稿，输入区在 @ 提及面板与输入框之间插入一条 32px 高的轻提示条：左侧 16px `table` 图标 + `--text-2` 文案「检测到表格」，右侧「发送为图片」文字按钮（茶青 `--primary`）与 14px `x` 忽略按钮。提示条底色 `--bg-list`、圆角 8px、`--line` 描边，不遮挡输入框也不改变输入框高度。默认 5 秒后自动消失；草稿超过单条文本上限时文案改为「表格过大，只能按图片发送」并**不自动消失**，避免草稿既发不出去、图片入口又已消失。用户改动草稿、切换会话、点忽略或点「发送为图片」后立即收起；点「发送为图片」会把刚插入的那段文本从草稿里摘掉再发图片，草稿中原有的其它内容保留。对方离线时「发送为图片」置灰（与工具条图片按钮同一门禁）。淡入使用 120ms opacity，`prefers-reduced-motion` 下直接显示。
- **表格图片消息（决议 #190）**：从 Excel / WPS / LibreOffice / 网页表格粘贴出的表格经上述提示条确认后作为图片消息发送；若该图片带 `tableText`，气泡内容上沿显示一个小型分段滑块「图片 / 文字」。滑块不覆盖图片，位于内容上方 4px，自己的消息右对齐、对方消息左对齐；整体高度约 24px，底色使用 `--bg-list` / 深色对应 token，选中滑块为茶青 `--primary`，选中文字白色，未选中文字用 `--text-2`。默认选中「图片」并展示原缩略图；切到「文字」后，同一气泡下方改为只读等宽文本视图，保留制表符和换行，支持鼠标选择与复制，内容高度设上限并内部滚动，避免撑高聊天流。若 `tableTextTruncated` 为 true，文字块上方以 `--text-3` 小字显示「文字视图已截断，图片完整」，提示不进入可复制 TSV 区域。图片查看器点击只在图片视图生效；文字视图不打开看图器。滑块切换只影响本机显示，不发网络报文、不改变消息状态。滑块位移与内容切换使用 150ms transform / opacity，`prefers-reduced-motion` 下直接切换。

- **截图工具条图标化（决议 #266）**：尺寸信息保留为紧凑数字；重新框选、矩形、箭头、文字、马赛克、发送、复制、取消八个功能按钮只显示 17px 线性图标，按钮命中区统一为 30×30px。工具组与操作组之间放一条 18px 半透明竖线；当前工具使用茶青底，发送使用实色茶青，取消仅在 hover 时呈克制红色。所有按钮保留中文悬停提示、键盘焦点环和无障碍名称，工具按钮暴露选中状态；图标全部来自本地 `PantryIcon`，禁止 emoji、字符拼图或外部资源。
- **截图按钮提示（决议 #267）**：鼠标停在任一功能按钮约 250ms 后显示对应中文气泡，键盘焦点进入按钮时立即显示；气泡使用 12px 系统字体、近黑背景、白字和小方向箭头，不遮挡图标。默认显示在按钮上方，工具条顶部坐标小于 48px 时整组提示翻到按钮下方；移出或失焦立即淡出。每个按钮使用独立 `data-tooltip`，可见提示与 `aria-label` 文案一致；不叠加浏览器原生 `title`，避免出现双重提示。

- **截图初始化可见性（决议 #218）**：截图窗出现时必须已能接收并展示桌面截图，动态入口晚于 `did-finish-load` 挂载时由 preload 回放最近一次初始化数据；加载间隙使用纯黑底色，不得透出茶青页面背景或形成整屏灰绿色遮罩。验收需实际完成「打开截图 → 看见桌面 → 拖拽框选 → 工具条出现 → Esc 退出」。

- **截图工作区与流畅度（决议 #221）**：Windows 框选蒙层只覆盖系统工作区，任务栏保留为真实系统界面且不进入可选截图范围；桌面画面与蒙层客户区必须等比例、同边界，禁止把含任务栏的整屏图片纵向压缩。蒙层显示前先完成桌面位图解码与首帧布局，用户看到的第一帧就是可框选桌面。框选时页面只保留一份桌面图，选区外由上 / 右 / 下 / 左四块半透明纯色遮罩变暗；鼠标移动按屏幕刷新帧合并，Win7 软渲染下不得随高频鼠标事件重复绘制第二份全屏背景。马赛克编辑态使用静态网格预览，确认时再生成真实像素化结果，不使用实时模糊。
- **截图失败反馈（决议 #286）**：点击截图后若屏幕源不可用、返回空图、主窗口无法完全隐藏或主进程抛错，主窗口恢复并在顶部居中显示 7 秒可关闭提示条（警示图标 + 明确原因/退路，`role=status`、`aria-live=assertive`）；提示不依赖系统通知，Chrome 108 下只使用既有主题变量。原本隐藏主窗时用全局快捷键触发失败，则优先以系统通知提示而不擅自打断；通知不可用时才显示主窗。所有退路统一说明可用系统截图后在聊天框 `Ctrl+V`。
- **ARM64 Wayland 截图退路（决议 #289）**：该平台组合在 Electron 22 枚举屏幕源前直接显示上述失败提示，不隐藏主窗、不打开框选窗；用户使用系统截图后仍可在聊天框 `Ctrl+V` 发送。x64 Wayland、ARM64 X11 与其他平台入口不变。

- **输入区材质升级（决议 #216）**：输入区从贴底平面改为离窗口边缘 14px 的浮起材质容器，使用 16px 圆角、内描边和轻阴影；工具按钮按下立即缩放，发送按钮使用主色实底突出。减弱透明度偏好下使用不透明表面，高对比偏好下增加清晰边框。

- **文件发送入口（决议 #174）**：聊天工具条的「文件」和「文件夹」按钮保持现有普通发送路径，点击后直接打开系统选择器，不在发送前弹「直接发送」菜单。私聊发送成功后，若符合条件，再在发送方文件卡片上出现「直接发送」按钮；群聊文件 / 文件夹入口始终只走普通发送。

- **兼容会话输入区（决议 #194/#195）**：由 `ConversationCapabilities` 统一控制，只显示文本输入框、历史搜索和发送按钮；表情、表情包、PK、窗口震动、截图、图片、文件、文件夹、直接发送、媒体撤回入口全部隐藏。空输入不可发送；粘贴图片 / 文件时只保留文本内容，若剪贴板没有文本则给轻量提示「内网通兼容会话暂不支持发送图片或文件」。发送失败时气泡保留失败态，用户可修改后重发。

- 表情面板双页签：**emoji** / **我的表情包**。emoji 页显示 Twemoji 本地 SVG 图标，点击仍向输入框插入对应 UTF-8 emoji 字符；输入框编辑态与消息气泡正文展示时对内置 emoji 子集替换为同套 SVG，避免 Win7 / UOS 显示方框。表情包来源：聊天里任意图片右键「添加到表情」，或点面板头部「导入」通过系统图片多选框添加；**保存时自动压缩**（静图最长边 512px 转 WebP，GIF 动图 ≤2MB 原样保留）。面板内右键删除、按钮排序；点击即发送，群聊仅在至少一位其他成员在线时可用。面板不会因鼠标移出自动关闭，仅在点击面板与表情按钮以外区域时关闭；固定高度内容区的每一行按表情实际宽度保留正方形高度，超出后纵向滚动，切换页签或表情包为空时弹出框尺寸保持稳定。
- Enter 发送、Ctrl/Cmd+Enter 换行（设置可互换）。
- 群聊中输入 `@` 弹出成员选择浮层，被 @ 者收到加强通知（会话列表标"[有人@我]"红字，P1，决议 #22）。
- 粘贴图片 → 输入框出现预览块再发送；**拖文件/文件夹到聊天区任意位置即普通发送**（拖入时全区高亮蒙层提示）。私聊拖入文件不提供直接发送预选；发送成功后若符合条件，由发送方文件卡片显示「直接发送」按钮。群聊拖入文件只走普通发送，不出现直接发送入口。

### 6.1 会话内历史搜索

群聊与私聊的输入区工具条最右侧显示“历史搜索”图标按钮。点击后弹出设置页尺度的居中面板，范围固定为当前会话；再次点击、切换会话、点击面板外遮罩或右上角关闭按钮均可关闭。面板宽高参考设置页的桌面软件感，优先保证筛选区、日期区、结果区稳定可扫描，不遮挡输入框内部控件。

面板内容：左侧为关键词输入框、“全部 / 图片 / 文件”分段筛选与连续日期范围选择，右侧为结果列表。打开面板时即显示当前会话最近记录；未输入关键词时按当前类型与日期筛选直接列出匹配记录。日期筛选使用单月日历组件：第一次点击选起始日，第二次点击结束日并高亮连续区间；再次点击可重新选择范围，清空筛选会一并清除日期。

**结果项信息密度（决议 #74）**：以快速扫读为先。文本命中**直接以摘要为主体**（可换行至两行），不再显示“文本消息”小标题与前置类型图标；文件命中显示类型图标 + 文件名；图片命中必须展示图片缩略图而不是只显示图片名，缩略图不可用时才回退为图片占位。所有结果项底部显示发送者与时间。摘要中的内置 emoji 与消息展示一致，走 Twemoji 本地 SVG 彩色渲染，Win7 / UOS 不再出现方框或黑白线描。**命中交互**：文本与文件命中单击即跳转到对应历史位置并短暂高亮；**图片命中单击放大查看（复用大图查看器、不离开搜索面板），双击才跳转定位**，便于快速浏览图片而不丢失搜索上下文。

## 7. 关键流程

### 7.1 发起讨论组（参考微信：从单聊加人）

单聊头部 `⋯` →「添加成员」，或会话列表 `[+]` → 弹出**两步建群弹窗**。

第 1 步是联系人快速搜索与多选：顶部输入框用于按备注/昵称/公司/部门/团队/IP 即时过滤联系人，下面是紧凑单行结果列表（复选框 + 在线点 + 姓名 + 右侧组织路径 + 离线标记）。公司 / 部门 / 团队以中点连接，始终与姓名同一行，空间不足时只省略组织路径并通过悬停标题查看完整内容；成员项最小高度 34px。底部显示已选人数与已选成员条。几百人规模下不要求用户靠滚动定位联系人（决议 #237）。

第 2 步是组设置：组名可留空，默认使用"张三、李四、王五的讨论组"；管理密码可留空，若填写则必须再输入一次确认一致，并可填写密码提示。建群者成为群主；群主和管理员管理时免密码，普通成员可输入管理密码执行改名或移出普通成员。

**建群提交与关闭手势（决议 #269）**：点击“创建”后保留当前组名、密码提示和成员选择，按钮显示“创建中”，返回、取消和遮罩关闭暂时锁定。成功后进入新群会话；参数校验或 IPC 异常时恢复按钮并在设置页显示行内错误，用户可以原地重试。点击遮罩关闭必须从遮罩空白处按下并在遮罩空白处结束；从组名等输入框开始拖选文字，即使指针移到弹窗外再松手，也保持弹窗与已填内容。

群成员面板按成员原顺序展示，并在姓名后显示小型「群主」「管理员」徽标。所有在群成员都能看到「添加成员」；点击后打开全局模态弹窗，沿用建群第一步的紧凑单行联系人、搜索和多选交互。搜索覆盖备注、昵称、公司、部门、团队、IP 与主机名；已有成员不进入候选，在线与离线联系人均可选择，已选项跨搜索结果保留并显示可移除标签。弹窗明确显示已选人数与群剩余名额，一次确认批量邀请；失败时保留选择并就地提示，提交期间禁止重复确认、遮罩关闭与 Esc 关闭。弹窗通过 Teleport 挂到 `body`，打开时聚焦搜索框，关闭后把焦点还给「添加成员」按钮（决议 #242）。

群成员面板顶部显示 64px 圆形群头像、群名和成员数（决议 #243）。群主、管理员及持有正确管理密码的普通成员可点击头像上的编辑按钮，选择本地图片后进入共用头像裁剪弹窗；有管理密码的普通成员沿用面板内密码输入与行内错误。自定义群头像同步显示在会话列表、群聊头部和该面板；恢复默认后立即回到成员群组图标。修改和恢复期间保留裁剪状态，成功后关闭并显示群系统提示。

群简介与群公告显示在群成员面板的群头像下方；空内容不占位置（决议 #290）。群主、管理员及持有正确管理密码的普通成员可通过面板底部入口打开同一套文本编辑弹窗。简介上限 200 字，公告上限 1024 字；已有内容清空后仍可保存，保存空串即恢复未设置状态。密码成员复用面板内管理密码与行内错误，成功后立即刷新本地群视图。弹窗通过 Teleport 挂到 `body`，支持遮罩、取消与 `Esc` 关闭，打开时聚焦文本框，关闭后恢复原按钮焦点；提交期间禁止重复保存和关闭。

群主可用盾牌按钮设置/取消管理员，并可移出管理员或普通成员；管理员只对普通成员显示移出按钮。群内存在未声明 `gr1` 的旧版本成员时，面板显示不阻断操作的升级提示。邀请、踢人、退群、任免管理员、改名和群主自动转让均写入居中的系统提示。

### 7.2 接收文件

对方发文件 → 我方聊天里出现文件卡片（右侧一行动作：「接收」主按钮 + 文件夹图标另存 + `x` 拒绝）→ 点击「接收」时默认保存到 `文件保存位置/联系人名称/`，点击文件夹图标「另存为」时保存到用户选择的目录 → 接收后显示进度 → 完成后卡片变为「打开 / 打开所在文件夹」。接收中若发送方并发预算已满而排队（决议 #211），进度行以「已传 / 总量 · 排队等待发送方」代替速率，不显示假 0 速度。接收方点「取消」后（对端为新版本时）卡片显示「已取消」徽标 + 「重新下载」按钮，点击按已收 `.part` 断点续传重新拉取；对端为旧版本或发送方主动取消 / 撤回时不提供重新下载。传输失败仍显示「继续」断点续传；领取期限内即使应用重启，也会从持久化上下文恢复该入口，缺少有效上下文时不显示不可用按钮。私聊直接发送自动接收也使用同一默认联系人子目录。群聊文件卡片同样出现在群会话里，发送端一条卡片汇总各在线成员的接收进度；接收方手动接收群文件时按发送人显示名进入联系人子目录。**单聊 ≤20MB 图片、群聊 ≤10MB 图片免确认**，直接以图片形式展示；群聊超过 10MB 的图片按普通文件卡片展示并手动接收。会话不在前台时走通知 + 角标。

**文件领取期限（决议 #263）**：普通私聊文件与群聊文件统一只可在发送后 24 小时内首次接收、继续或重新下载。到期后所有接收操作消失，发送方卡片显示灰色「发送已到期」，接收方显示灰色「文件已过期」。截止前已经开始的当前传输保留进度并允许完成，截止后失败或重启中断则转为过期。群发卡片继续展示「已接收 x/y」和成员名单，领取窗口结束且仍有成员未完成时右侧显示「发送已到期」。私聊直接发送也受同一期限约束；图片、表情和隐藏更新包不展示普通文件过期状态。

发送方撤回文件 → 若接收方尚未完成保存，双方隐藏文件卡并显示撤回系统提示；接收方传输中则自动取消并清理未完成临时文件。若接收方已经完成保存，发送方不再能撤回该文件，接收方本地文件保持可用。

### 7.3 托盘 / 菜单栏与通知（点击直达会话）

- 新消息：托盘 / 菜单栏 tooltip 始终显示未读总数；macOS 菜单栏图标旁显示未读数字，并同步 Dock 角标；Windows 使用任务栏 overlay 数字，同时托盘图标在原图标与带数字角标图标之间闪烁；Linux 尝试系统角标（Unity 支持时生效），默认让常规茶青图标与高对比红色注意图标每 800ms 交替，确保 UOS/DDE 的小尺寸系统托盘中也能看清变化（决议 #214）。未读清零后所有数字与闪烁停止并恢复常规图标。**未读判定（决议 #220）**：只有窗口可见且聚焦时，当前打开会话的新消息才即时置读；最小化、关到托盘或被其他窗口压住失焦期间，当前会话的新消息同样计入未读并触发托盘闪烁 / 角标，重新聚焦窗口后当前会话未读自动清零、闪烁停止。
- 桌面通知摘要必须兼容 Win7 / UOS 缺字环境：通知正文不渲染 emoji 图形，文本里的内置 emoji / 常见 emoji 统一显示为 `[表情]`；表情包通知显示 `[表情]`，图片显示 `[图片]`，文件显示 `[文件] 文件名`，PK 显示 `PK · 猜拳` 或 `PK · 骰子` 且不展示结果。Linux / Windows 通知显式带真实应用图标，避免 UOS 通知中心显示系统默认图标（决议 #108/#139）。
- **点击通知或托盘 → 主窗弹出并直接定位到对应会话**（用户原话需求）。
- 托盘右键：打开主窗 / 全局免打扰开关 / 退出。

### 7.4 首次启动向导（决议 #22）

首次打开必经三步，防止全网一片"未命名"：① 昵称（必填，默认取系统用户名）→ ② 公司 / 部门 / 团队（选填，可跳过）→ ③ 文件保存目录确认 → 进主界面。中途退出则下次启动重新进入向导。向导首屏顶部使用真实品牌标识（`PantryBrandLogo` color 变体纯图形 + `茶话间 Teahouse` 中英文字标，与关于页 / 空状态一致，决议 #122/#155），不使用纯文字占位。第三步文案说明该目录用于存放收到的文件，不写"功能即将到来"——文件收发已是核心能力。

### 7.5 给离线的人发消息

正常输入发送 → 气泡时钟态 + 会话内一次性灰字提示"对方当前离线，将在其上线后自动送达"→ 对方上线后自动补发，气泡转 ✓。

### 7.6 局域网自更新（决议 #166）

主界面发现内网有**同平台、版本更高、可作更新源**的在线节点时，给一个**不打扰的提示入口**——主导航栏 / 列表栏顶部一枚淡茶青「内网有新版」徽标（带小红点），不弹窗打断当前操作；无更可用更新源时完全不显示。点开 → **更新弹窗**：显示新版本号、来源同事昵称、当前版本，操作「同步更新」；内网范围、不访问外网、索包不静默安装等机制说明收进圆形 `?` 帮助图标，hover / focus 时显示自绘 tooltip，不作为正文常驻。点「同步更新」→ 向该节点发起内网索包请求；当前实现仅提示请求中 / 已发出 / 暂不可用，不展示普通文件传输卡片。后续进度形态：后台从该节点拉取（复用文件传输的进度展示）→ 拉完校验通过提示「即将重启更新」→ 自动安装重启（Windows 静默完成、Linux 弹一次系统授权框）。失败给明确文案并可重试，不影响继续聊天。整套提示遵循 tokens 茶青单主色 / 8px 圆角 / 明暗主题 / `prefers-reduced-motion`。本期覆盖 Windows 安装版与 Linux deb，mac 暂缓。

### 7.7 内网通兼容模式（决议 #194/#195）

用户在「设置 → 网络」打开内网通兼容开关，填写独立 IP 段或手动节点，点击「扫描兼容节点」。扫描期间只在设置页网络组显示进度，不占用左侧主导航的全局刷新按钮；发现节点后立即进入通讯录「内网通兼容」分组，并在联系人名称和会话头部显示「内网通」徽标。用户双击兼容联系人进入兼容会话后，可发送普通文本；收到兼容节点主动消息时，若联系人尚未在列表中出现，则以临时兼容联系人加入分组并创建会话。兼容模式状态异常时使用明确短文案：`2425/UDP 被占用`、`兼容模式未开启`、`未配置兼容 IP 段`、`未发现兼容节点`。IPMSG 文件 / 剪贴板图片 offer 在首版不开放普通发送入口；若后续实验开关启用，统一渲染为“兼容文件”卡片，操作只保留接收、另存为和拒绝。

### 7.8 共享文件柜（决议 #271–#277、#283）

**开自己的文件柜**：导航栏「文件柜」→ 列表栏「我的文件柜」→ 「选择目录」（拦截主目录根 / 系统盘根 / 应用数据目录并说明原因）→ 选默认权限档（不共享 / 只读 / 可读可传，默认**不共享**）→ 需要时给个别同事加例外。全部即时保存（决议 #150/#151），底部弹「设置已保存」胶囊。（v0.50 前该入口在「设置 → 聊天与文件 → 我的文件柜」，决议 #283 迁出。）

**去别人的文件柜**：两条路——① 导航栏「文件柜」→ 列表栏点同事 → 内容区浏览器；② 私聊 → 头部「文件柜」按钮 → 右侧 320px 面板。然后逐级双击进子目录 → 勾选文件 / 子目录 → 「下载 N 项」→ 进度就地显示，默认落到 `文件保存位置/文件柜-对方名称/`，也可「另存为」。面板头部的「在文件柜里打开」可把当前对端带进文件柜页签。

**往别人的文件柜放东西**：底栏「上传到 TA 的柜子」（仅有写权限时出现），或直接把文件 / 文件夹拖进浏览区 → 文件进入对方 `共享根/我的名字/` → 对方在与我的私聊里看到一条系统提示「我 上传了 N 个文件到你的文件柜」，点击可打开该目录；对方也能在自己的「我的文件柜」页看到「最近有人放进来」里的这一条（决议 #283）。**只有上传会提示；别人浏览、下载我的文件柜全程静默**（决议 #274）。

**拿不到时的表现**：对方离线 / 未开文件柜 / 未对我开放 / 版本过旧，入口按钮灰显并在悬停时说明原因，绝不给出"能点但点了没反应"的入口。

## 8. 设置页与文件柜页

### 8.1 设置页

独立设置窗口（640×480，微信式），左侧分组导航，右侧为「页头说明 + 分组面板 + 设置行」。设置窗弹出时居中到主窗几何中心（决议 #123），而非屏幕中心——主窗被拖到副屏或角落时设置窗跟随主窗，并夹取到主窗所在显示器工作区防止越界。设置窗同主窗为沉浸式无标题栏（决议 #49）：顶部 32px 隐形拖拽带，macOS 红绿灯内嵌，Windows / Linux 右上角仅自绘关闭按钮。设置页不按实现先后排列，而按用户心智与常见桌面软件规范组织：先身份与外观，再通知、聊天文件、网络，最后快捷键和关于（**决议 #150 重组为 7 组**：端口归「网络」、发送键归「聊天与文件」、去掉「安全与高级」杂物抽屉）。每个设置行包含标题、说明、控件。**保存策略统一（决议 #150 / #151）**：所有设置**即时保存**——偏好（开关 / 主题 / 字体 / 提示音 / 发送键）调整即生效，文本输入（资料 / 端口 / 快捷键 / 文件位置）失焦(blur)即存、头像与目录选定即存；**不再有任何保存按钮**（仅保留「更改」浏览、「恢复默认」「重置应用设置」等动作按钮）。每次保存后底部居中弹出「设置已保存」深色胶囊 toast，淡入 + 轻微上移、停留约 1.8s 后淡出（决议 #151，尊重 `prefers-reduced-motion`）；值未变则跳过不弹，昵称空 / 端口越界则复原原值并提示原因。二选一偏好（主题、发送键）用分段控件而非下拉。视觉沿用 4px 间距台阶与 4 级字号阶梯；决议 #216 将形状标尺升级为面板 14px、标准控件 8-10px、胶囊 999px。未实现能力不摆置灰占位，做好再加。

**头像编辑器**（决议 #50/#243/#244/#245）：左侧 64px 圆形大预览 + 当前样式小字（如「自定义头像」/「动物表情 · 茶青」/「昵称首字 · 湖蓝」）；右侧顶部按「动物表情 / 昵称首字 / 自定义头像」排列三段切换。动物表情模式在下方展示 10 列 × 2 行的动物网格和 10 色背景色板；昵称首字模式隐藏动物网格，只展示同一背景色板，选色立即保存；自定义头像模式隐藏动物和色板，只展示一个「上传图片」按钮，已有自定义头像时继续使用该按钮更换图片。切换到动物表情或昵称首字会立即应用相应预设并清除自定义图片；切换到自定义头像只改变编辑面板，上传裁剪成功后才应用。取消选择或裁剪保持原头像。

**头像裁剪弹窗**（决议 #243/#246/#247/#249）：用户和群共用，通过 Teleport 挂到 `body`。中心工作区以圆形遮罩显示最终头像范围，图片默认居中覆盖；鼠标或触控板拖动调整位置，滚轮、缩放滑杆及加减按钮调整大小，重置恢复初始居中。拖动从工作区按下开始后由窗口级鼠标事件持续跟踪，放大、移出工作区或短暂丢失局部命中时仍可继续调整，抬起、窗口失焦或卸载立即结束。最小缩放始终填满圆形范围；最大缩放随源图动态放宽——允许一直放大到裁剪区域约等于 192px 输出分辨率（如 8192px 源图约 42 倍），小于输出分辨率的源图不放大，缩放步进按当前倍率等比（×1.12），拖动边界不露空白；固定输出 192×192 WebP，大图降采样经 `createImageBitmap` 高质量缩放避免锯齿（决议 #249）。应用时直接从原始受检图片字节解码位图，编码前拒绝全透明裁剪结果，失败保留位置与缩放并显示行内错误。弹窗打开时聚焦关闭/缩放控制，支持遮罩、取消与 Esc 关闭并恢复触发按钮焦点；应用期间锁定关闭和重复提交。静态 JPG/PNG/WebP/BMP 可用，GIF、APNG、动态 WebP、源文件超过 20MiB、单边超过 8192px 及解码失败均给出明确提示。所有颜色、圆角、阴影和字号使用现有 token，减少动态效果时取消缩放进场。

**设置侧栏**（决议 #238/#239）：顶部拖拽带下方直接排列「账号资料 / 通用 / 通知 / 聊天与文件 / 网络 / 快捷键 / 关于」分组导航，不重复展示当前头像、昵称或公司摘要；完整身份编辑只出现在右侧「账号资料」页。每项文字前放置 18px 自绘线性图标，语义依次为身份卡、调节滑杆、通知铃、聊天文件、局域网节点、键盘、信息圆标。图标统一使用 1.6px 圆角描边并继承行文字颜色，默认次级灰、悬停提高对比、选中随文字变为茶青；图标与文字间距 9px，整行继续保持 38px 高度和左侧选中强调线。

**端口修改确认**（决议 #240）：网络页 UDP / TCP 端口输入框默认显示当前值并保持只读；点击或键盘聚焦后弹出居中风险确认框，标题按入口显示「确认修改 UDP 端口？」或「确认修改 TCP 端口？」。正文固定为：「UDP/TCP 端口共同用于局域网发现、消息和文件传输。修改后需要重启应用，并确保相关客户端、防火墙及网络策略使用匹配配置；配置不一致可能导致联系人无法发现、消息或文件无法送达。」下方强调：「只有在你明确了解当前网络部署，并已准备同步调整相关配置时，才建议继续。」按钮从左到右为「取消」和红色高亮「确认修改」，初始焦点落在安全区域；Esc、遮罩和取消均关闭提示并保持原值。确认后仅当前输入框进入可编辑状态并自动聚焦 / 全选，失焦后恢复锁定并按既有 1–65535 校验保存。

**分段偏好滑块（决议 #223/#245）**：账号资料的三段头像模式、通用的二段主题、聊天与文件的二段发送键共用同一视觉结构。底座使用列表层中性色，选中项以窗口表面、轻阴影和茶青前景浮起；按钮按下即时轻微缩放，键盘焦点显示清晰茶青外环。主题滑块保持紧凑，只显示本地线性太阳 / 月亮图标，分别代表浅色 / 深色，并保留完整无障碍名称；发送键显示 `Enter` / `Ctrl/Cmd+Enter`。减少动态效果时取消位移动画。

**发送键图标化（决议 #224）**：发送键滑块不再显示长串平台缩写。第一段用单个回车键帽图标；第二段由两个键帽与一个弱化加号组成，macOS 显示 Command + 回车，Windows / Linux 显示 Control + 回车。键帽使用 22px 紧凑方形、5px 圆角、1px 内描边，图标保持本地线性风格；整组宽度从约 198px 收紧到约 134px。按钮的 `aria-label` 保留平台化完整语义，视觉和读屏结果一致。

**材质升级（决议 #216）**：侧栏使用较厚的半透明结构材质，页头移除贯穿硬分割线，分组面板使用 14px 圆角、柔和内描边与有色阴影；导航选中态使用弱茶青底和左侧强调线。Naive UI 控件统一采用 8-10px 控件圆角，并保留即时保存行为。

**保存提示定位（决议 #218）**：「设置已保存」toast 按整个 640×480 设置窗口水平居中，使用 `left: 50%` 配合自身半宽位移；不得继续补偿侧栏宽度而偏到右侧内容区中心。

### 8.2 文件柜页（主窗第三个页签，决议 #283/#284）

文件共享是高频功能，入口从设置窗第三组提到导航栏。**形态是主窗的第三个页签，不是独立窗口**（决议 #284）——主窗本来就是「导航 + 列表栏 + 内容区」，文件柜正好占后两格；多开一个窗口只是把同一件事拆到两处，还多一套窗口生命周期。**入口**：导航栏底部工具组最上一格（更新提示之下、刷新之上），`cabinet` 线性图标 21px（柜体 + 一道分层线 + 两个抽屉把手，1.6px 描边、继承文字色），沿用既有 `rail-hint` 悬停气泡「文件柜」与聊天 / 通讯录同款选中态；**不加未读角标**（有人上传已在私聊冒泡计未读，同一件事不提醒两次）；未设共享目录时按钮照常可点，进去是引导设置的空态。

**页面骨架**：沿用主窗三栏，切到本页签时——**列表栏（272px）**换成文件柜列表，**内容区**换成文件浏览器或「我的文件柜」管理页；导航栏不动。列表栏顶部让出 36px 拖拽带（与会话列表搜索栏同口径，决议 #127），本页签**不显示全局搜索框**（文件柜自带「搜索同事」，全局搜索在这里没有意义）；内容区头部 52px + 32px 拖拽带 = 84px，与聊天头部等高。

**列表栏**分两段：① **「我的文件柜」摘要卡**——12px 圆角、`--material-strong` 底 + 细描边，卡内三行键值（共享目录路径 / 默认权限 / 单独设过的同事 N 人），选中时改茶青弱底 + 茶青描边；未设目录时整卡换成一句「未开启」+ 「选择目录」主按钮。② **同事的文件柜列表**——分组标题行（「同事的文件柜」+ 计数）、搜索框（人多时过滤），每行 50px：32px 圆头像带在线/离线状态点 + 显示名 + 副标题（在线给部门 · IP、离线给「离线 · 最后在线 …」、旧版本给「版本较旧，不支持文件柜」）。列表只收**通讯录里声明 `shr1` 的联系人**，在线在前、离线灰显在后（决议 #17 口径）。离线与旧版本条目**仍可点**，右栏就地说明原因并给「重试」——不做点不动的死按钮。**权限徽标不在列表里**：有效权限由对方当场判定、只有列过一次目录才知道，为渲染列表批量探测会撞对方 10 秒 5 次的列目录限流。

**内容区 · 浏览器**自上而下五段：① **头部 52px**——32px 圆头像 + 「XX 的文件柜」+ 副标题（在线状态 · IP · 共 N 项）；右侧依次是权限徽标（「只读」灰底 /「可上传」茶青弱底）、列表/网格分段控件、刷新图标。② **面包屑行 40px**——返回上级箭头 + `文件柜 / 设计稿 / 2026`（任意一级可点）。③ **表头 28px**——全选复选框 + 名称 / 大小 / 修改时间（右对齐，`--text-3` 11.5px）；还有下一页时全选标签为「选择已加载」（决议 #281）。④ **列表区**——详情行 40px：复选框（未勾选时只在 hover 显示）、22px 文件类型图标（复用 `file-types` atlas，目录用文件夹图标）、名称（单行省略 + `title` 全名）、大小与修改时间（`tabular-nums` 等宽数字，目录不显示大小）；hover 淡灰底、选中茶青弱底；滚到底自动取下一页（每页 200 条）并显示骨架行。⑤ **底栏两行**——上行左「已选 N 项 · 合计大小」，右「另存为…」「上传到 TA 的柜子」（仅有写权限）「下载 N 项」（茶青实心，未勾选时不出现）；下行常驻 `--text-3` 小字讲清落点（下载到 `文件保存位置/文件柜-对方名称/`、上传进对方柜子里以我命名的文件夹），**避免误以为传到当前目录**。传输进度、速率、剩余、取消就地显示在底栏上方的一条进度行里（细进度条 + 一行文字），**不进聊天流**。

**网格视图**：卡片 108px 高、5 列自适应，42px 大图标 + 两行文件名居中截断，选中为茶青 1.5px 描边 + 左上勾选框。视图偏好记在本机界面偏好里（与共享设置无关），私聊内 320px 面板恒为列表（宽度放不下网格）。两种视图都**不做缩略图预览**（要给协议加取图报文，且会把"翻个目录"变成成片图片传输），也**不提供排序切换**（列表分页取回，本地重排会让翻页顺序错乱）。

**浏览手感对齐系统文件管理器**：单击选中、**双击进目录**（原「单击目录即跳走」取消）、`Ctrl`/`⌘` 加减选、`Shift` 选范围、`↑`/`↓` 移动、`Ctrl`/`⌘`+`A` 全选已加载、`空格` 勾选、`Enter` 进目录或下载单个、`Backspace`（mac 亦支持 `⌘`+`↑`）返回上级、`F5` / `⌘`+`R` 刷新、`Esc` 取消选中；右键菜单只有**下载 / 另存为… / 复制文件名**，**没有删除与重命名**（协议层就不提供改动别人文件的能力，决议 #272）。有写权限时整个浏览区接受拖入上传（茶青虚线高亮 + 「松手就放进 XX 的柜子」+ 落点小字），无权限显示禁止态说明。

**内容区 · 我的文件柜页**：头部（柜子图标 + 「我的文件柜」+ 副标题「正在共享 · 同事按下面的权限访问」+ 右侧「停止共享」文字按钮），下面四张卡片——① **共享目录**（路径行 + 「打开」「更改…」，一句说明"同事看不到它在你磁盘上的位置"）；② **默认权限**（三段滑块「不共享 / 只读 / 可读可传」，下方随档位切换说明文案，选到"可读可传"补一句"只能放新文件，不能删改覆盖"）；③ **单独设过的同事**（紧凑三列表格：头像 + 显示名（离线灰显）/ 权限下拉 / ✕ 移除即恢复跟随默认；表格下一行「可搜索联系人下拉 + 添加」，新例外默认「只读」；无例外时空态「所有同事都按默认权限」）；④ **最近有人放进来**（决议 #283 新增，读既有传输记录里 `purpose='share-put'` 的条目，按人按次列最近 10 条：头像 + 「XX 放进来 N 个文件 · 合计大小」+ 右侧时间，点任意一条打开本机对应目录；一句说明"别人只是浏览、下载不会出现在这里"）。全部即时保存并弹既有「设置已保存」胶囊（决议 #150/#151），共享根被拒时就地红字说明原因。

**空态与失败态**（口径与私聊面板一致，决议 #278）：还没开柜子 → 引导态「你还没有开文件柜」+ 「选择共享目录」；对方关柜 / 未对我开放 → 首屏整片替换为居中错误态 + 「重试」；**翻页失败只在列表末尾追加一行小字 + 「重试」，已加载条目一律保留**并暂停自动续拉；空目录 →「这个文件夹是空的」（有写权限时补「可以把文件拖进来」）；截断 → 底部小字「目录内容过多，仅显示前 5000 项」（常量插值）；对方离线 / 版本过旧 → 说明原因并点明"文件柜要双方都开着软件才能访问"。
